# TODO

ブラウザだけで動くシンプルな TODO アプリです。ビルドやインストールは不要で、依存ライブラリもありません。

## 使い方

`index.html` をブラウザで開くだけで使えます（ダブルクリックで OK）。

| 操作 | 方法 |
| --- | --- |
| 追加 | 入力欄に書いて Enter または「追加」 |
| 完了 / 未完了 | チェックボックス |
| 編集 | ✎ ボタン、またはタスク名をダブルクリック → Enter で保存 / Esc で取り消し |
| 削除 | × ボタン（直後に「元に戻す」で取り消せます） |
| 絞り込み | フッターの「すべて / 未完了 / 完了済み」（URL の `#/active` などでも切り替わります） |
| 一括操作 | 「すべて完了にする」「完了済みを削除」 |

- 日本語入力の変換確定の Enter で誤って追加・保存されないようにしています。
- ライト / ダークモードはOSの設定に合わせて切り替わります。
- スマートフォンの画面幅にも対応しています。

## データの保存

タスクはブラウザの `localStorage`（キー: `todo-app:v1`）に保存されます。

- 保存先はブラウザごと・開き方（`file://` か `http://localhost` か）ごとに別になります。
- 同じブラウザの別タブで変更すると、もう一方のタブにも反映されます。
- プライベートモードなどで保存できない場合は、画面上部に警告が表示されます。

## ファイル構成

```
index.html          画面の HTML
style.css           スタイル（ライト / ダーク）
src/todo-core.js    ロジック（追加・完了・編集・削除・絞り込み・データ読込）。DOM に依存しない純粋関数
src/app.js          画面の描画とイベント処理、保存
tests/              ブラウザで動くテスト
```

## テスト

`tests/index.html` をブラウザで開くとテストが実行されます。

- そのまま（`file://`）開いた場合: ロジックの単体テストのみ実行し、UI テストはスキップされます。
- 実際の画面を操作する UI テストも実行するには、ローカルサーバー経由で開きます。

```sh
python3 -m http.server 8000
# → http://localhost:8000/tests/ を開く
```

UI テストは保存先を `todo-app:v1:uitest` に分けているので、普段使っているデータには影響しません。
